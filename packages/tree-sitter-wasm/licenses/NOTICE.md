# Embedded grammar provenance

`sources.json` records the pinned sources corresponding to these notices.
Grammar and runtime license files are copied from those dependency archives.

The pinned Bash query archive lacks the LICENSE file referenced by its README.
That README describes extraction from nvim-treesitter and labels the queries MIT.
The original nvim-treesitter license is retained here as `nvim-treesitter.txt`
([upstream source](https://github.com/nvim-treesitter/nvim-treesitter/blob/master/LICENSE));
its Apache terms are not replaced by the extracted repository's README label.
