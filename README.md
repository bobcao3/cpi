# cpi

Cheng Cao's extensions and skills for the [pi coding agent](https://pi.dev).
Better file editing, background work, and visibility into what agents are doing.

## Install

Requires pi 0.85.1 or newer.

```sh
pi install git:forge.bc3.moe/bob/cpi
```

Installed for your user account, available across projects.
